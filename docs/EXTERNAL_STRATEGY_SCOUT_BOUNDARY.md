# External Strategy Scout Boundary

`US_stocks_strategy_scout_DISCOVERY_ONLY` is a separate local project. Yahoo
bars, screening returns, charts, gate metrics, caches, and run directories are
never Stocks V2 inputs or evidence.

Stocks V2 may read only a bounded `frozen_strategy_spec.json`. That file defines
a hypothesis and non-authoritative exposure claims without carrying market
data or performance. Intake does not authorize registration, outcome access, training,
evaluation, sealing, prediction, monitoring, paper testing, or trading.

The current project accepts only the existing D1-open/D5-close,
`linear_distribution_v1`, `prospective_price_only_v1`, and
`multiclass_log_loss` contracts. Other horizons, feature schemas, and
deterministic-rule models remain scout-only until a separate scientific change
is reviewed and authorized.

Even a compatible specification remains blocked until the exact historical and
external exposure census, required accepted prospective releases, a real
registration committed locally and backed up to the configured GitHub branch,
a qualifying sealed bundle, and separate prospective execution authority all
exist.

Only a content-addressed Stocks V2 census assessment covering legacy records,
current-project records, manual reports/plots, and external outcome exposures
can clear the exact-census gate. Any uninspected source or unresolved attempt
keeps the state `INDETERMINATE_BLOCKS_TRUSTED_GATE`.

The compatible scout adapter reproduces the frozen hypothesis shape for cheap
screening, but Yahoo-adjusted results remain `DISCOVERY_ONLY_PROXY`, never raw
causal project evidence. Donchian 20/200 remains scout-only.

The accepted prospective lane requires at least 2,268 sessions under the
current contract. A bounded AAPL/SPY smoke cannot satisfy that horizon or
activate the source.
